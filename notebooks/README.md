# Notebook praktikum

Setiap modul memiliki dua notebook:

- `demo.ipynb`: alur demonstrasi dosen/asisten dan smoke test konsep inti.
- `starter-mahasiswa.ipynb`: kerangka individual berisi checkpoint dan `TODO`.

Salin starter menjadi `MXX_NIM.ipynb`; jangan mengerjakan langsung pada file
starter. Semua notebook harus dijalankan melalui **Restart Kernel and Run All**
sebelum dikumpulkan. Simpan tabel eksperimen mengikuti
`../templates/template-metrics.csv`.
